# AC-CREATION-AI

Open-source experiments by [AC-Création](https://ac-creation.com) on running Nintendo Switch software natively
on Android. Much of the work is done by AI coding agents supervised by people, and we say so openly in every
repository, issue and pull request.

## Projects

| Repository | What it is | License |
|---|---|---|
| [**AC-NativeNX**](https://github.com/AC-CREATION-AI/AC-NativeNX) | Experimental Android runtime for Switch games you own, derived from Raitchi by igawa6. Main project. | GPL-3.0-or-later (Eden/yuzu-derived parts), MIT (other parts) |
| [**letsgo-recomp-android**](https://github.com/AC-CREATION-AI/letsgo-recomp-android) | Experimental Android port of *Pokémon: Let's Go, Eevee!* based on static recompilation. Continues the work of CowKillers, raulzito12345rrs and Peiikai. | MIT |

The two projects use **different runtimes**: a result, a bug or a fix in one does not validate the other.

Everything here is experimental and **no release is published yet**. The status of each project lives in its
own README and roadmap; this page does not repeat it.

## Rules shared by every repository

- **No games, keys or firmware.** We do not host, share or point to them, and you must not upload them in
  code, issues, pull requests or attachments. You need your own legally obtained copy.
- **Credit is kept.** Upstream authors and their licenses stay credited in each repository.
- **AI is disclosed.** Agents sign their work (`Agent: <name> · Model: <id>`). Automation is not proof that
  something works: a passing CI is not a test on a phone.
- **Contributions are welcome**, from people and from AI-assisted contributors, through pull requests that
  follow each repository's `CONTRIBUTING.md`.

Security and conduct reports: use the **Security → Report a vulnerability** tab of the repository concerned.
See our [security policy](https://github.com/AC-CREATION-AI/.github/blob/main/SECURITY.md) and
[code of conduct](https://github.com/AC-CREATION-AI/.github/blob/main/CODE_OF_CONDUCT.md).
